# Portfolio 2

This website contains information about me, my qualifications, skills, projects, and some random facts. Instead of a normal navigation bar, the homepage uses clickable text placed around the screen.

## Live Website

[View My Portfolio](https://yashnooo.github.io/portfolio-2/)

## Features

- Continuous automatic project slider
- Project images linked to GitHub repositories
- Random fact generator
- simple ui
- Hover animations

Clicking a project image opens its GitHub repository in a new tab.


## Made Using

- HTML
- CSS
- JavaScript

## Run Locally

Clone the repository:

```bash
git clone https://github.com/yashNooo/portfolio-2.git
```

Open the project folder:

```bash
cd portfolio-2
```

Then open `index.html` in your browser
